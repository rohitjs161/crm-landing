# CRM360 – Modern CRM Landing Page

A modern, responsive, and animation-rich marketing website for a **360° CRM platform** built with **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS**, **GSAP**, and **Framer Motion**.

This project was developed as part of the **Full Stack Developer Intern screening task** at **Instabizweb**. The primary focus was to create a premium SaaS landing page with clean UI, reusable components, smooth animations, and production-ready code.

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/crm-landing.git
```

Go to the project directory:

```bash
cd crm-landing
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

# 📦 Production Build

Build the project:

```bash
npm run build
```

Start production server:

```bash
npm start
```
